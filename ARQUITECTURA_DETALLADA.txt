🎯 app.js - COORDINADOR PRINCIPAL
----------------------------------
QUÉ HACE:
- Es el "cerebro" de toda la aplicación
- Inicializa todos los demás sistemas en el orden correcto
- Maneja eventos globales (shortcuts, resize, online/offline)
- Coordina la comunicación entre todos los módulos

FLUJO DE INICIALIZACIÓN:
1. Crea instancia de CharacterDatabase
2. Inicializa TabCoordinator para navegación
3. Instancia todos los tabs (Gallery, Collection, Teams, AI)
4. Registra tabs con el coordinator
5. Configura event listeners globales
6. Actualiza estadísticas del header

PUNTOS CLAVE:
- Singleton pattern: solo una instancia de OctopathApp
- Error handling robusto con pantalla de error
- Debugging: expone objetos globalmente (window.galleryTab, etc.)
- Toast notifications system

DÓNDE CAMBIAR QUÉ:
- Agregar nuevos tabs: método _initializeTabs()
- Modificar shortcuts globales: método _setupGlobalHandlers()
- Cambiar orden de inicialización: método init()

---------------------------------------
QUÉ HACE:
- Carga y gestiona TODOS los datos de personajes

🎯 MarkdownIntegrator.js - PARSER DE CONTENIDO RICO
---------------------------------------------------
QUÉ HACE:
- Carga y parsea archivos markdown de personajes (246 archivos)
- Convierte markdown a estructura de datos JavaScript
- Implementa sistema de caché inteligente por tier
- Extrae secciones: Skills, Latent Powers, EX Skills, etc.

LÓGICA DE CARGA:
1. _findMarkdownFile(): busca archivo correcto por nombre
2. fetch() carga contenido markdown desde servidor
3. _parseMarkdownContent(): convierte a objeto estructurado
4. Caché con TTL basado en tier del personaje

SISTEMA DE BÚSQUEDA DE ARCHIVOS:
- Lista completa hardcoded de 246 archivos markdown
- Búsqueda por coincidencia exacta de nombre
- Maneja caracteres especiales (apostrophes, acentos)
- Fallback a búsqueda aproximada si no hay match exacto

PARSEO DE CONTENIDO:
- Extrae Passive Skills con iconos y descripciones
- Identifica Battle Skills con SP cost y potency
- Separa Latent Powers y Ultimate Techniques
- Maneja EX Skills y Awakening Accessories

DÓNDE CAMBIAR QUÉ:
- Agregar nuevo tipo de contenido: crear método _extract[TipoContenido]()
- Modificar parsing: método _parseMarkdownContent()
- Cambiar caché behavior: método _getCachePriority()

🔄 FLUJO DE DATOS (Data Flow)
================================================================================

📥 INICIALIZACIÓN (App Startup)
-------------------------------
1. OctopathApp.init()
2. CharacterDatabase.init() carga en paralelo:
   - octopath_optimized.json
   - 8 archivos de índices
   - frontend_config.json
3. GalleryTab.init() setupea UI
4. Usuario ve 30 primeros personajes ordenados por tier

📊 FILTRADO Y BÚSQUEDA
----------------------
1. User interactúa con filtro/search
2. GalleryTab._handleFilterChange() actualiza this.currentFilters
3. CharacterDatabase usa índices para filtrado O(1):
   - Tier filter → indexes.byTier[selected_tier]
   - Job filter → indexes.byJob[selected_job]
   - Search → indexes.searchTerms.filter(matches)
4. Combina resultados usando Set intersection
5. Aplica sorting (tier-first por defecto)
6. Renderiza page actual (30 items)
7. Actualiza pagination UI

🖼️ APERTURA DE MODAL (Character Details)
-----------------------------------------
1. User click en character card
2. GalleryTab._openCharacterModal(character)
3. RichModalRenderer.renderEnhancedModal() crea estructura
4. MarkdownIntegrator.loadCharacterMarkdown() en background:
   - Busca archivo markdown correcto
   - Fetch del archivo si no está en caché
   - Parse a estructura JavaScript
   - Caché con TTL basado en tier
5. RichModalRenderer actualiza tabs con contenido rico
6. Usuario ve modal completo con tabs navegables

💾 PERSISTENCIA DE DATOS
------------------------
1. User marca character como owned/favorite
2. CharacterDatabase actualiza character.user_data
3. _saveUserData() persiste a localStorage
4. UI se actualiza inmediatamente (badges, indicators)
5. Data persiste entre sesiones
